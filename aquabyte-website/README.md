# AquaByte website starter

Responsive single-page website prototype based on the AquaByte website content document.

## Run the website
1. Extract the ZIP file.
2. Open this folder in Visual Studio Code.
3. Open `index.html` in a browser. You can optionally use the VS Code Live Server extension.

## Project files
- `index.html`: page structure and content.
- `css/style.css`: colours, typography, layouts, responsive styles and contact form appearance.
- `js/script.js`: mobile navigation, current year and demo form feedback.
- `assets/`: place approved images and logo files here.

## Important limitations
- The pond illustration and farmer dashboard are visual concepts, not connected to real devices.
- The enquiry form validates required fields in the browser but does not send or store submissions.
- Connect a backend or trusted form service before using the form in production.
- Review draft legal content and confirm contact details before publishing.
- The website describes intended capabilities; don't claim untested results as proven facts.
